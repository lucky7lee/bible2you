# 오늘 성경 말씀 To You (Bible To You) 📖✨

> **"주의 말씀은 내 발에 등이요 내 길에 빛이니이다" (시편 119:105)**  
> 오늘 나의 얼굴 표정과 삶의 자리를 비추어 주님이 예비하신 **맞춤 성경 말씀, 깊은 묵상, 하루 실천 과제, 1분 기도문**을 선물합니다.

## 🕊️ 프로그램 소개

**"오늘 성경 말씀 To You"**는 성명과 생년월일, 그리고 오늘의 얼굴 상태(웹캠 스캔 또는 사진 업로드)를 분석하여 그리스도인이 오늘 하루를 살아가는 데 꼭 필요한 영적 양식을 맞춤형으로 제공하는 온디바이스 AI 기독교 묵상 웹 애플리케이션입니다.

---

## 🌟 주요 기능 및 특징

### 1. 나에게 해당하는 오늘의 성경 말씀
- 창세기부터 요한계시록까지, 성경 66권 중 오늘 나에게 가장 필요한 생명의 말씀을 장/절과 함께 제시합니다.
- 말씀의 시대적 배경과 오늘을 살아가는 성도에게 전하는 은혜의 조명을 함께 제공합니다.
- **음성 낭독 (TTS)** 지원: 버튼 하나로 은혜로운 목소리로 말씀을 귀로 들으며 묵상할 수 있습니다.

### 2. 오늘 해야 할 묵상 내용
- **얼굴 상태 영적 진단**: 오늘 나의 얼굴에 나타난 수고와 피로, 잔잔한 평강, 혹은 기쁨의 미소를 기독교적 시각에서 따뜻하게 진단합니다.
- **깊은 묵상 가이드**: 오늘 하루를 거룩하게 살아갈 수 있는 영적 통찰을 제공합니다.
- **마음에 품을 3가지 질문**: 일상 속에서 곱씹을 수 있는 실천적 묵상 질문을 제시합니다.

### 3. 오늘 하루 실천해야 할 작은 일 (Faith in Action)
- 오늘 하루 꼭 감당할 **핵심 미션 1가지**
- 말의 축복, 선한 섬김, 작은 결단 등 **구체적인 실천 과제 3가지** (인터랙티브 체크리스트 제공)

### 4. 오늘의 1분 기도문
- 아침을 열거나 하루를 마무리할 때 하나님께 온전히 올려드릴 수 있는 은혜로운 1분 기도문
- **"아멘 🙏" 버튼**: 기도를 마음에 품고 아멘으로 화답할 때 축복의 은혜 파티클 효과 제공

### 5. 기독교인을 위한 은혜의 선물
- **오늘의 추천 찬양/CCM**: 제목, 찬양 사역자 및 은혜로운 가사 한 줄 소개
- **오늘의 작은 영적 습관**: 일상 속에서 실천할 수 있는 10초 감사기도, 성경 읽기 장 추천

### 6. 나이와 얼굴 상태 기반 정밀 매칭
- **생애주기 분석**: 어린이·청소년, 청년, 장년, 중년, 시니어 등 인생의 계절에 맞춘 축복 메시지
- **얼굴 상태 테마 (6대 영적 영역)**:
  - 🌿 **안식과 쉼 (Rest)**: 피로하고 지친 얼굴 → 위로와 참된 쉼의 말씀 (마 11:28, 시 23편 등)
  - ☀️ **기쁨과 감사 (Joy)**: 환한 미소 → 구원의 기쁨과 찬양의 말씀 (살전 5:16-18, 빌 4:4 등)
  - 🦁 **용기와 담대함 (Courage)**: 생기와 결단 → 믿음의 돌파와 승리의 말씀 (수 1:9, 빌 4:13 등)
  - 🕊️ **지혜와 인도 (Wisdom)**: 진지함과 집중 → 하늘의 분별과 명철의 말씀 (잠 3:5-6, 시 119:105 등)
  - ❤️ **사랑과 온유 (Love)**: 온화한 표정 → 십자가의 사랑과 섬김의 말씀 (고전 13장, 요 13:34 등)
  - 🌊 **샬롬과 평강 (Peace)**: 고요하고 평온함 → 흔들리지 않는 평안의 말씀 (빌 4:6-7, 창 1:1-3 등)

### 7. 철저한 프라이버시 보호
- **100% 온디바이스 AI (MediaPipe FaceLandmarker)**: 촬영된 영상과 사진은 외부 서버로 전송되지 않으며, 사용자 기기 브라우저 내부에서만 안전하게 분석됩니다.

## 🛠️ 기술 스택

- **Frontend**: React 18, TypeScript, Vite
- **Face AI Vision**: Google `@mediapipe/tasks-vision` (478 Face Landmarks & Blendshapes)
- **Icons**: `lucide-react`
- **Voice / Audio**: Web Speech Synthesis API
- **Deployment**: GitHub Pages, GitHub Actions CI/CD

## 💻 로컬 개발 및 실행

```bash
# 1. 저장소 복제
git clone https://github.com/lucky7lee/bible2you.git
cd bible2you

# 2. 패키지 설치
npm install

# 3. 개발 서버 실행
npm run dev

# 4. 프로덕션 빌드
npm run build
```
